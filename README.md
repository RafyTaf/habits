# Habits

A weekday habit tracker you can save to your iPhone Home Screen like an app.

## Add to Home Screen (iPhone)

1. Open this site in **Safari** (not Chrome or the in-app browser):
   https://rafytaf.github.io/habits/
2. Tap the **Share** button (the square with an up arrow).
3. Scroll down and tap **Add to Home Screen**.
4. Make sure the name is **Habits**, then tap **Add**.

The icon appears on your Home Screen. Opening it launches Habits full-screen, and your check-offs stay saved on this phone.

## Notes

- Weekdays (Mon–Fri) are tracked. Weekends pause tracking and do not break streaks.
- Use **Edit** to add, rename, reorder, or delete routines and activities.
- Active streaks use an orange-red fire. A streak of zero uses an icy blue snowflake.
